# [S] crabx init

## Goal

`crabx init`, run in a crate's repository, writes the caller of
[the pipeline](../../../.github/crabx/README.md), pinned to its release, and nothing else.
The workflow it writes takes no inputs.

## Required

- [Pipeline release](/quest/m2/crabx/pipeline-release.md) - a verified version tag to pin
