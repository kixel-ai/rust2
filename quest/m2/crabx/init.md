# [S] crabx init

## Goal

`crabx init`, run in a crate's repository, writes the caller of
[the pipeline](/quest/m2/crabx/pipeline.md), pinned to its release, and nothing else.
The workflow it writes takes no inputs.

## Required

- [The pipeline](/quest/m2/crabx/pipeline.md) - the reusable workflow `init` calls
